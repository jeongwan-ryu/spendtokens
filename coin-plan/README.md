# 코인 매매 계획판

Bybit USDT 무기한 선물 시세로 **쉬어야 할 구간을 보여 주고, 진입 전에 "틀렸을 때"를 먼저 계산하는** 개인용 매매 계획 도구입니다. 파일 하나(`index.html`)로 동작하며 서버나 API 키가 필요 없습니다.

> 투자 조언이 아닙니다. 선물 거래는 레버리지로 원금 이상 잃을 수 있습니다. 이 페이지는 거래소의 손절 주문을 대신하지 못하니, 실제 손절은 거래소에 스탑 주문으로 걸어 두세요.

## 기능

- **관망 보드** — 코인별로 상승 추세 / 하락 추세 / 쉬는 구간을 1분·15분·1시간·4시간 탭마다 표시합니다. 추세 효율(20봉), EMA50 기울기, 상위 봉 방향이 모두 맞을 때만 추세 구간으로 봅니다.
- **매매 계획** — 진입가·손절가·손익비·레버리지를 넣으면 1회 위험금에 맞춘 수량, 증거금, 예상 청산가, 손절 시 손실(수수료·미끄러짐 포함), 5·10번 연속 손실 시 계좌 변화를 보여 주고 원칙 확인 목록을 점검합니다.
- **매매 일지** — 기록한 매매가 손절·목표가에 닿으면 팝업·소리·시스템 알림으로 알려 주고, 실제 손익과 승률, 최대 연속 손실을 쌓습니다.
- **감시 상태** — 마지막 시세 수신 시각과 감시 중인 보유 종목 수를 보여 줍니다. 시세가 끊겼다 돌아오면 그 사이 1분봉으로 손절·목표 도달 여부를 다시 확인합니다.
- **실험 규칙 모의 기록** — 후보 규칙 하나를 알림 없이 모의 거래로만 기록합니다.
- 화면의 `?`와 점선 밑줄 용어를 누르면 설명이 나옵니다.

## 실행

- **Windows에서:** 저장소를 받은 뒤 `coin-plan\start.bat`을 더블클릭하면 `http://localhost:8791`이 열립니다. Node·Python 설치는 필요 없습니다. 브라우저 알림은 localhost나 https에서만 동작하므로 `index.html`을 파일로 직접 열기보다 이 방법을 권합니다. 8791 포트를 다른 프로그램이 쓰고 있으면 `serve.ps1`의 `$port` 값을 바꾸세요.
- **우분투·리눅스·맥에서:** `./coin-plan/start.sh`를 실행하면 `http://localhost:8791`이 열립니다(python3 필요, 우분투 기본 포함). 포트를 바꾸려면 `PORT=8800 ./coin-plan/start.sh`.
- **웹에 올릴 때:** GitHub Pages를 저장소 루트로 켜면 `https://<아이디>.github.io/<저장소>/coin-plan/`에서 열립니다.

## 알아둘 점

- 감시와 알림은 **페이지가 열려 있고 시세가 들어오는 동안만** 동작합니다. 탭을 닫거나 PC가 절전·잠금 상태면 멈춥니다.
- 일지·계좌 설정은 브라우저(localStorage)에만, 사이트 주소별로 따로 저장됩니다. 브라우저 데이터를 지우면 사라집니다.
- Bybit를 차단하는 지역에서는 시세를 받을 수 없습니다.

## 검증 결과 요약 (2026-10)

10개 코인, 수수료 0.11% 포함 백테스트에서 지표 점수(EMA·RSI·MACD·볼린저·캔들·거래량) 신호는 모든 봉 단위에서 손실이었고, 추세 구간만 골라도 나아지지 않았습니다. 미결제약정 이벤트 규칙도 처음 찾은 기간 밖에서는 통하지 않았습니다. 그래서 이 페이지는 매수·매도 신호를 보내지 않고, 쉬는 구간 구분과 위험 계획에 집중합니다.
